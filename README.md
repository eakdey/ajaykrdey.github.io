# Shri Ajay Kumar Dey — My Life

Welcome to the official source code and repository for my personal digital archive: **[deykrajay.github.io](https://eakdey.github.io)**.

This repository serves as a static site built for **GitHub Pages** using **Jekyll**, bringing together historical research, Bengali literature, devotional writing, books, poetry, and intellectual work.

---

## 📚 Archive Sections

* **Research Desk:** Historical studies, source-based essays, academic notes, and long-form research articles.
* **Katha & Seva:** Devotional literature, Bhagwat Katha material, spiritual reflections, and service notes.
* **Literary Room:** Bengali poems, Vaishnava Padavali, books, lyrics, and literary creations.
* **Book Shelf:** Published books, bibliography, and catalogued research publications.

---

## 🛠️ Tech Stack & Structure

* **Hosting:** GitHub Pages (Free, secure, and fast static hosting)
* **Engine:** Jekyll / Kramdown Markdown
* **Styling:** Custom SCSS editorial magazine theme inspired by academic research archives.
* **Services:** Integrated Google Form links for Bhagwat Path & Katha booking enquiries.
